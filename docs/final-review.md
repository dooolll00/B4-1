## 한계와 남은 작업

- 제공 앱은 미션의 키 파일 경로와 다른 디렉터리·파일 이름을 요구합니다. 원래 지정 파일을 보존하고 호환 파일로 부팅했습니다. README에 차이와 실제 대응을 명시했습니다.
- 기존 운영 사진은 이전 코드의 증빙입니다. 최신 코드의 서버 확인 결과는 이 문서에 요약했습니다. 원본 운영 로그와 환경변수 값은 저장하지 않습니다.
- 10MiB 초과 파일을 외부에서 강제로 생성한 경우 크기를 줄이지 않습니다. 정상 스크립트가 생성·추가하는 로그의 상한을 검사합니다.
- cron.log는 관제 출력 확인용 별도 로그이며 monitor.log 로테이션에는 포함되지 않습니다. 장기 운영에서는 별도 보존 정책이 필요하지만 이번 필수 monitor.log 조건과 구분합니다.
- 보너스 report.sh 및 시간 기반 압축·삭제는 미구현입니다.
- GitHub에 최신 제출본을 업로드하는 작업이 남아 있습니다.
